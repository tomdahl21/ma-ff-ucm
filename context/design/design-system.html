Data Provenance — Source System Language

The central product thesis is that this app joins Epic and Salesforce. That claim is only credible if every value on screen carries its origin. These colors are reserved exclusively for source attribution — never for decoration. UCM maroon is reserved for the orchestration layer itself, i.e. work this app did.

Source Tag — .src
Epic Salesforce Agentforce Marketing Cloud

Used inline anywhere a value appears: table headers, timeline entries, risk factors, recommendation footers. Small enough to be unobtrusive, consistent enough to be learned once.

Where each component is used
ComponentPurposeAppears On
.src Inline origin tag on any single value All app views
.prov-bar Persistent strip under app bar — live connection + sync lag per system Coordinator, Manager, Executive
.prov-factor Risk factor row tagged with contributing system and point weight Coordinator detail rail
.conflict Epic vs. Salesforce disagreement + the resolution rule applied Coordinator detail rail, Manager reconciliation panel
.merge Two source records converging into one unified record Available — not yet placed
.arch Before/after silo diagram for executive storytelling Executive

Rule of thumb: if a number could plausibly have come from either system, tag it. If a coordinator might act on it, tag it and show its freshness.
